# Heaven's Arena League Rulebook

> Draft. The full rulebook is written in a later build step. This file is the source of truth for rule text; the site's Rules page renders it.

## 1. General

1.1 HAL is a free-entry, NA-only Call of Duty: Modern Warfare 4 league. HAL follows the current CDL ruleset and Gentlemen's Agreements (GAs) unless this rulebook says otherwise.

1.2 All league times are America/New_York (ET).

1.3 Admin decisions are final.
